# Student Registration Form

A simple Student Registration Form built using **HTML5 and CSS3** as part of my Python Full Stack Development learning journey.

## Features

- Student name, email, and password fields
- Gender selection using radio buttons
- Multiple skill selection using checkboxes
- Date of Birth input
- Register button with hover effect
- Styled input fields with focus effects
- Submitted students table with formatted headings and content

## Technologies Used

- HTML5
- CSS3

## Concepts Practiced

- HTML Forms and Input Types
- Labels, IDs, Names and Values
- Radio Buttons and Checkboxes
- CSS Selectors
- Box Model
- Padding and Margin
- Background Colors and Typography
- Hover and Focus Pseudo-classes
- Table Styling and Text Alignment
